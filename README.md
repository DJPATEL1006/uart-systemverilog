# UART Transmitter in SystemVerilog

## Overview

A parameterized UART transmitter implemented in SystemVerilog for FPGA/ASIC design.

### Features

- Parameterized data width
- Configurable baud rate divider
- Even/Odd parity support
- Modular RTL design
- GTKWave verified

## Architecture

- UART FSM
- Baud Generator
- Bit Counter
- Shift Register
- Parity Generator
